## 本文

メルカリやラクマで物を売っていて、こんな経験はありませんか？

- 9,800円で売れて喜んだのに、振り込まれた金額を見たら思ったより少なかった
- 何をいくらで仕入れたか、もう覚えていない
- 年末になって、1年分の売上を慌てて集めている

私もフリマで売るたびに、電卓とメモアプリを行ったり来たりしていました。そこで、**利益計算と在庫管理をひとつにまとめたアプリ「フリマ帳」** を作りました。

この記事では、まず**フリマの利益を正しく計算する方法**を説明し、そのあとでアプリの使い方を紹介します。アプリを使わない方にも役に立つ内容にしています。

### 1. フリマの利益は「4つ」を引いて考える

販売価格から、次の4つを引いた金額が、本当の利益です。

> **利益 ＝ 販売価格 − 販売手数料 − 送料 − 仕入れ値 − 梱包材などの経費**

| 項目 | 内容 |
|---|---|
| 販売手数料 | 販売価格の○%。メルカリは10%です |
| 送料 | 出品者が送料を負担する場合にかかります。配送方法とサイズで変わります |
| 仕入れ値 | その商品を買ったときの金額 |
| 梱包材など | 封筒・緩衝材・テープなど |

**例：スニーカーを9,800円で売った場合**

| | 金額 |
|---|---|
| 販売価格 | 9,800円 |
| 販売手数料（10%） | −980円 |
| 送料（80サイズの例） | −850円 |
| 仕入れ値 | −4,200円 |
| 梱包材 | −30円 |
| **利益** | **3,740円（利益率 38.2%）** |

9,800円で売れても、手元に残るのは3,740円です。「売れた金額」と「儲かった金額」は、これだけ違います。

※ 手数料と送料は改定されることがあります。最新の金額は、各サービスの公式ページで確認してください。

### 2. 値付けは「目標の利益率」から逆算する

「いくらで出品すればいいか分からない」ときは、逆に考えると決めやすくなります。

> **販売価格 ＝ （仕入れ値 ＋ 送料 ＋ 梱包材）÷（1 − 手数料率 − 目標利益率）**

たとえば、仕入れ4,200円、送料850円、梱包材30円で、**利益率30%** を取りたい場合は、

（4,200 ＋ 850 ＋ 30）÷（1 − 0.10 − 0.30）＝ 8,467円

なので、**8,500円以上**で出品すれば、利益率30%を確保できます。

### 3. 計算と記録をアプリで一度に済ませる

ここまでの計算を毎回電卓でやるのは大変です。「フリマ帳」は、この計算をスマホで一瞬で行い、そのまま記録まで残せます。

（画像：利益計算の画面）

**使い方**
1. 販売先（メルカリ・ラクマ・Yahoo!フリマなど）と配送方法を選ぶ
2. 仕入れ値と販売価格を入れる
3. 利益と利益率、目標利益率を取るための価格がすぐ表示される
4. 「在庫として保存」または「売れた！で保存」を押す

（画像：在庫一覧の画面）

保存した商品は、**在庫・出品中・売却済** に分けて管理できます。どの商品でいくら儲かったかが一覧で分かります。

（画像：集計の画面）

集計画面では、1年の**売上・利益・在庫金額**と、**月ごとの利益のグラフ**を見られます。

### 4. 確定申告の準備にも

フリマで不用品ではなく、仕入れた商品を売っている場合は、利益が一定額を超えると確定申告が必要になることがあります。

フリマ帳の **PRO（買い切り2,980円）** では、1年分の **売上・仕入れ・手数料・送料・利益** を、Excelでそのまま開けるCSVファイルで出力できます。年末にレシートや取引履歴をかき集める手間がなくなります。

※ 確定申告が必要かどうかや、具体的な手続きは、税務署や税理士に確認してください。

### 5. フリマ帳の特長

- **登録不要**：ブラウザで開くだけで、すぐ使えます
- **アプリのインストールも不要**：「ホーム画面に追加」すると、アプリのように起動できます
- **データは自分のスマホの中だけ**：サーバーには送信されません
- **30件まで無料**：たくさん売るようになったら、PRO（買い切り2,980円・月額なし）で無制限になります

### おわりに

フリマは「売れた」が楽しい反面、手数料や送料で利益が思ったより残らないことがよくあります。出品する前に一度、利益を計算するクセをつけるだけで、赤字の出品はぐっと減ります。
