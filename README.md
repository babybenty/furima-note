# フリマ帳 — フリマ出品者向け 利益計算・在庫管理アプリ

メルカリ・ラクマ・Yahoo!フリマ などの個人セラー向けPWA。手数料と送料を差し引いた利益をその場で計算し、在庫と売上を記録して、確定申告用CSVを出力できる。

## 市場調査の要約（2026年10月）

| 観点 | 調べて分かったこと |
|---|---|
| 個人開発の勝ち筋 | 汎用ツールより、特定業種の業務に合わせた「バーティカル」なツールが選ばれやすい。現実的な目標は月5万円程度から |
| 既存の競合 | 「かんたん利益計算」は計算専用で、記録の保存や商品名の登録ができない。「セラーブック」は買い切り3,600円で売上管理（＝お金を払う層がいる証拠） |
| 隙間 | **計算 → 在庫 → 売上 → 確定申告CSV** を1つの流れでつなぐ、軽くてシンプルなツールが少ない |
| 見送った案 | インボイス対応の請求書（freeeなど無料の大手が強い）、習い事教室の管理（無料アプリが多く、決済連携が前提になる） |

**ターゲット**：副業でせどりやフリマ販売をしている人。年間20万円を超える所得には申告が必要なので、記録を残す・申告に使うという実際の困りごとがある。

## 収益モデル

- **無料版**：登録30件まで・広告あり（集客の入口）
- **PRO**：買い切り ¥2,980（既存の買い切り3,600円より安くして乗り換えを狙う。月額プランは、キーの自動更新の仕組みができてから検討）
  - 登録無制限 / 確定申告CSV / 販売先別の分析 / 滞留在庫アラート / 広告なし
- 試算：PRO買い切り 月20本 ≒ 月6万円

## 機能

- 利益計算（手数料・送料・梱包材込み）、損益分岐価格、目標利益率からの価格逆算
- 販売先くらべ（同じ価格で各フリマに出したときの利益を比較）
- 写真つきの在庫管理（仕入れ先・メモ・出品日、絞り込み・並べ替え・検索、複製、削除の取り消し）
- 年別・月別の売上と利益、販売先別の分析、売れ残り在庫の損益分岐（PRO）
- 経費の記録と確定申告の集計：売上原価＝期首在庫＋仕入−期末在庫、所得の目安、CSV・印刷（PRO）
- 販売先・配送方法の追加と編集
- IndexedDB に保存（写真含む）。旧バージョンの localStorage から自動移行。写真込みのバックアップと復元、30日ごとのバックアップ通知
- データは端末内のみに保存（サーバー不要で運用費ゼロ、個人情報を預からない）
- `npm test` で計算ロジック（`core.js`）の単体テストを実行

## 注意点と今後の改善

- ライセンスは電子署名で検証している。秘密鍵がなければキーを作れないが、アプリのコードを書き換えればPROの機能を解除できてしまう（ブラウザで動くアプリの限界）。少額の買い切りなので、MVPとしてはこれで十分と判断
- 手数料と送料の初期値は2026年10月時点の公開料金をもとにしている。公開前に各サービスの公式ページで確認すること
- 今後の候補：バーコードで商品登録、複数端末の同期（有料機能）、ネイティブアプリ化（Capacitor）
